### Day 79 — Custom Helm Chart for AI-BankApp

**Goal:** Convert the 12 raw Kubernetes YAML files into **one reusable Helm chart**.

#### What you build

* Custom `bankapp` Helm chart
* `Chart.yaml` + configurable `values.yaml`
* Templates for:

  * Spring Boot BankApp Deployment
  * MySQL Deployment
  * Ollama Deployment
  * Services
  * ConfigMap
  * Secret
  * PVCs / StorageClass
  * HPA
* Conditional Ollama deployment using `ollama.enabled`
* Configurable images, replicas, resources, storage, credentials, and AI model

#### Key Helm concepts

```text
values.yaml
     ↓
Helm templates
     ↓
Rendered Kubernetes YAML
     ↓
Kubernetes cluster
```

Useful template functions:

```text
{{ .Values.x }}     → read configuration
{{ if }}            → conditional resources
{{ with }}           → work with nested values
{{ include }}        → reusable helpers
{{ toYaml }}         → convert values to YAML
{{ nindent }}        → correctly indent YAML
{{ b64enc }}         → encode secrets
```

#### Validate

```bash
helm lint bankapp/
helm template my-bankapp bankapp/
helm template my-bankapp bankapp/ --set ollama.enabled=false
```

The last command demonstrates that disabling:

```yaml
ollama:
  enabled: false
```

removes the Ollama Deployment, Service, PVC, and BankApp init container.

#### Deploy on Kind

```bash
helm install my-bankapp bankapp/ \
  -n bankapp --create-namespace \
  --set storageClass.create=false \
  --set mysql.persistence.storageClass=standard \
  --set ollama.persistence.storageClass=standard
```

Verify:

```bash
helm list -n bankapp
kubectl get all -n bankapp
kubectl get pvc -n bankapp
kubectl get configmap,secret -n bankapp
```

### Main takeaway

**12 hardcoded Kubernetes manifests → 1 configurable Helm chart.**

Instead of manually changing YAML for every environment, you change `values.yaml` or provide environment-specific values:

```bash
helm upgrade --install my-bankapp bankapp/ -f values-prod.yaml
```

This makes the AI-BankApp **reusable, configurable, versionable, and easier to deploy/rollback**.
