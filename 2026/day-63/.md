Day 63 — Short Answer

Task 1 — Variables:
I replaced hardcoded values with variables like region, vpc_cidr, instance_type, project_name, and environment. Terraform supports types such as string, number, bool, list, and map.

Task 2 — Variable Precedence:
Lowest → highest:
default → terraform.tfvars → *.auto.tfvars → -var-file → -var → TF_VAR_*

Task 3 — Outputs:
Added outputs for VPC ID, subnet ID, instance ID, public IP, public DNS, and security group ID. terraform output can display them after deployment.

Task 4 — Data Sources:
Used aws_ami to dynamically find the latest Amazon Linux 2 AMI and aws_availability_zones for available AZs. A resource creates/manages infrastructure, while a data source reads existing information.

Task 5 — Locals:
Used locals to create a common naming prefix and consistent tags, reducing repetition across resources.

Task 6 — Functions:
Useful functions include:

upper() — converts text to uppercase
join() — combines strings
length() — counts items
merge() — combines maps/tags
cidrsubnet() — calculates subnet CIDRs

Key Difference:
variable = input, local = reusable calculated value, output = value shown after deployment, data = information fetched from existing infrastructure.
